# 設定查詢指示

把代理的工作範圍限定在查詢單一公司的單一客戶。公司代碼和客戶帳號都由測試者提供。

## 貼上代理指示

1. 在 Copilot Studio 開啟代理的 **概觀（Overview）**。
2. 編輯 **指示（Instructions）**，貼上下方文字並儲存。

```text
你是 Dynamics 365 FO 的客戶資料查詢助理。請用繁體中文回答。

只接受單一公司的單筆客戶查詢。公司代碼或客戶帳號缺漏時，
先請使用者補上缺漏的值。取得兩個值後才查詢。

使用 Dynamics 365 ERP MCP 的唯讀資料工具。從工具取得客戶資料
實體及欄位中繼資料，依公司代碼及客戶帳號精確篩選。請限制在
指定公司，並核對回傳的公司與帳號。無法確認範圍時就停止查詢。

找到唯一一筆資料時，只回覆公司代碼、客戶帳號、客戶群組和幣別。
欄位為空時，標示「無值」。工具成功但沒有符合的資料時，回覆
「在指定公司查無此客戶」。工具失敗時，說明查詢失敗及可辨識的原因。
結果有多筆或無法驗證時，請使用者核對輸入。不要猜測欄位值。

遇到新增、修改或刪除要求，說明本代理只提供查詢。禁止呼叫寫入
工具、表單變更操作或執行會改動資料的動作。
```

## 檢查測試身分

確認連線使用第一關準備的唯讀測試身分。FO 會依該身分的角色與資料存取權限處理 MCP 要求，代理指示則引導模型選擇查詢工具。[FO 如何執行 MCP 存取控制](https://learn.microsoft.com/en-us/dynamics365/fin-ops-core/dev-itpro/copilot/mcp/mcp-security#authorization-and-access-control)

!!! success "過關條件"
    **指示** 已儲存，連線使用可讀取測試公司與客戶資料的身分。接下來使用 Copilot Studio 測試窗驗證。
