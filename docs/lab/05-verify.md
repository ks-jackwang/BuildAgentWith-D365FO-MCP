# 測試並核對結果

在 Copilot Studio 的 **測試代理（Test your agent）** 窗格完成三個測試。每次開啟新測試對話，避免前一題的公司或帳號影響結果。將下方角括號中的代稱連同括號換成第一關記下的值。[測試代理與活動圖](https://learn.microsoft.com/en-us/microsoft-copilot-studio/authoring-test-bot)

## 測試一　查詢已知客戶

```text
在公司 <公司代碼>，查詢客戶 <客戶帳號> 的客戶群組與幣別。
請列出公司代碼、客戶帳號、客戶群組和幣別。
```

1. 在測試窗開啟 **活動圖（Activity map）**。若未顯示，在測試窗的 **⋯** 開啟 **Show activity map when testing**。
2. 點選 ERP MCP 的資料查詢活動，檢視工具輸入和輸出。確認查詢範圍是指定公司，客戶帳號符合輸入，且活動成功回傳資料。
3. 回到 FO，確認公司選擇器指向同一家公司，再從 **所有客戶** 開啟該筆帳號。比對代理回覆和 FO 中的客戶群組、幣別。

**預期結果**　活動圖有成功的 MCP 查詢，且代理回覆的資料與 FO 相符。

## 測試二　省略公司代碼

```text
請查詢客戶 <客戶帳號> 的客戶群組與幣別。
```

**預期結果**　代理先詢問公司代碼。活動圖在這一輪沒有客戶資料查詢。

## 測試三　查詢不存在的帳號

```text
在公司 <公司代碼>，查詢客戶 <不存在的帳號> 的客戶群組與幣別。
```

**預期結果**　MCP 查詢成功但沒有符合的資料，代理回覆在指定公司查無此客戶。若活動圖顯示連線或權限錯誤，先到[常見問題](../troubleshooting.md)排查，再重測。

!!! success "完成 Lab"
    你已確認代理有實際呼叫 FO、欄位值與 FO 相符，並能處理缺少公司代碼及查無客戶兩種情境。

練習到此可結束。若這個代理專供練習且已用完，可以刪除它，並清理本次建立且未被其他資源使用的連線。
