# 用 ERP MCP 建立<br>客戶查詢代理

在 Copilot Studio 建立一個代理，查詢 Dynamics 365 Finance and Operations（FO）測試環境的客戶群組與幣別。用活動圖確認代理有呼叫 MCP 工具，再到 FO 核對欄位。

[開始實作 →](lab/01-environment.md){ .md-button .lab-start }

<p class="lab-hero-note">需要 FO UDE 或 Tier 2 以上的非正式環境，以及 Copilot Studio 製作者權限。</p>

</section>
